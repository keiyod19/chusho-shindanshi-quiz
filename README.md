# 中小企業経営・政策 300問 演習アプリ

中小企業診断士「中小企業経営・中小企業政策」の本番想定 300 問の演習Webアプリ。

## 使い方
### ローカル（PC）
`index.html` をダブルクリックしてブラウザで開くだけ（サーバー不要）。

### スマホ
`中小企業政策300問.html`（単一ファイル）を AirDrop / iCloud / メールで送り、
Safari で開く →「ホーム画面に追加」でアプリのように使えます（オフライン可）。

### Web公開（GitHub Pages）
`./deploy.sh <github-username>` を実行（事前に `gh auth login`）。

## 機能
- 分野別演習 / ランダム / 間違い復習 / 模試（40問）
- 即時採点・解説・進捗自動保存（localStorage）・分野別正答率
